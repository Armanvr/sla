# Mobile-First + PWA Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make all layouts responsive (mobile-first, 360px+) without breaking the existing desktop UI, then ship PWA support (installable, offline-capable).

**Architecture:** CSS changes are additive — base styles target mobile, `md:` (768px+) prefixes upgrade to desktop. PWA is added via `vite-plugin-pwa` (Workbox under the hood) configured in `vite.config.ts`. App icons are generated from an existing source image using `@vite-pwa/assets-generator`.

**Tech Stack:** Preact, Tailwind CSS v4, `vite-plugin-pwa`, `@vite-pwa/assets-generator`

### Task 3: Configure `vite.config.ts` with VitePWA

**Files:**
- Modify: `vite.config.ts`

- [ ] **Step 1: Replace vite.config.ts**

```ts
import preact from '@preact/preset-vite'
import tailwindcss from '@tailwindcss/vite'
import { defineConfig } from 'vite'
import { VitePWA } from 'vite-plugin-pwa'

export default defineConfig({
	plugins: [
		preact(),
		tailwindcss(),
		VitePWA({
			registerType: 'autoUpdate',
			workbox: {
				globPatterns: ['**/*.{js,css,html,png,svg,webp,woff2}'],
				runtimeCaching: [
					{
						urlPattern: /\/assets\//,
						handler: 'CacheFirst',
						options: {
							cacheName: 'assets-cache',
							expiration: { maxAgeSeconds: 60 * 60 * 24 * 30 },
						},
					},
					{
						urlPattern: /\.json$/,
						handler: 'StaleWhileRevalidate',
						options: { cacheName: 'data-cache' },
					},
				],
			},
			manifest: {
				name: 'SLA — Solo Leveling: ARISE Guide',
				short_name: 'SLA',
				description: 'Guide interactif pour Solo Leveling: ARISE',
				theme_color: '#000000',
				background_color: '#000000',
				display: 'standalone',
				orientation: 'portrait-primary',
				start_url: '/',
				icons: [
					{
						src: '/icons/icon-192.png',
						sizes: '192x192',
						type: 'image/png',
					},
					{
						src: '/icons/icon-512.png',
						sizes: '512x512',
						type: 'image/png',
						purpose: 'any maskable',
					},
				],
			},
		}),
	],
})
```

- [ ] **Step 2: Verify build succeeds**

Expected: build completes. Vite output should mention the service worker and manifest. Fix any import errors before continuing.

### Task 5: Mobile-first CSS — container and global fixes

**Files:**
- Modify: `src/styles/sla-elements.css`
- Modify: `src/styles/sla-mobile.css`

The `sla-container` currently uses a fixed padding that can be too tight on narrow screens. The bottom tab bar needs safe-area padding. Key grids are hardcoded to 3 columns.

- [ ] **Step 1: Update `sla-container` in `sla-elements.css`**

Find the existing `.sla-container` rule (around line 219):
```css
.sla-container {
	max-width: 1280px;
	margin: 0 auto;
	padding: 0 var(--sla-space-6);
}
```

Replace with:
```css
.sla-container {
	max-width: 1280px;
	margin: 0 auto;
	padding: 0 var(--sla-space-4);
}

@media (min-width: 768px) {
	.sla-container {
		padding: 0 var(--sla-space-6);
	}
}
```

(`--sla-space-4` is 16px, `--sla-space-6` is 24px — check `sla-tokens.css` to verify exact values. If tokens differ, use the 16px / 24px pattern.)

- [ ] **Step 2: Verify `--sla-space-4` value**

```bash
grep "sla-space-4\|sla-space-6" src/styles/sla-tokens.css
```
Confirm `--sla-space-4` is ≤ 16px and `--sla-space-6` is ≥ 20px. Adjust the mobile rule if needed.

- [ ] **Step 3: Add app bottom padding for BottomTabBar**

The BottomTabBar is 56px + safe-area. Main content needs matching bottom padding so it isn't obscured. Add to end of `sla-mobile.css`:

```css
/* Ensure content scrolls above fixed bottom tab bar */
.sla-app {
  padding-bottom: calc(56px + env(safe-area-inset-bottom));
}

@media (min-width: 768px) {
  .sla-app {
    padding-bottom: 0;
  }
}
```

- [ ] **Step 4: Hide BottomTabBar on desktop** (verify this already exists)

```bash
grep -A5 "sla-bottom-tab {" src/styles/sla-mobile.css | head -10
```

If `sla-bottom-tab` is NOT hidden at `md:`, add to `sla-mobile.css`:

```css
@media (min-width: 768px) {
  .sla-bottom-tab {
    display: none;
  }
}
```

If it's already hidden, skip this step.
